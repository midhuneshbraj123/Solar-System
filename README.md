# Solar-System

An interactive, CSS-animated 2D visualization of the Solar System built with vanilla HTML, CSS, and JavaScript.

## Description

**Complete Solar System** is a lightweight, browser-based astronomy simulation featuring the Sun and all eight planets (Mercury, Venus, Earth, Mars, Jupiter, Saturn, Uranus, and Neptune) orbiting in real time. Each planet is rendered with distinct sizing, color styling, and relative orbital animation speeds powered by pure CSS keyframe animations, paired with a JavaScript-driven control interface to pause and resume orbital motion on demand.

## Getting Started

### Dependencies

* A modern web browser with CSS3 and ES6 JavaScript support (e.g., Google Chrome, Mozilla Firefox, Microsoft Edge, or Safari).
* No external libraries, frameworks, or build tools are required.
* Works on any operating system (Windows, macOS, Linux).

### Installing

1. Clone or download the repository to your local machine:
   ```bash
   git clone <your-repository-url>
Navigate into the project directory:

Bash
cd <project-folder-name>
Ensure all three core project files remain in the same root directory:

index.html

styles.css

script.js

Executing program
Locate index.html in your project folder.

Open index.html directly in your preferred web browser (double-click the file, or right-click and choose Open with → your browser).

(Optional) Serve locally using a development server such as VS Code Live Server or Python:

Bash
python -m http.server 8000
Then visit http://localhost:8000 in your browser.

Click the Pause Orbits button at the bottom of the screen to freeze planetary motion, and Resume Orbits to continue.

Help
Planets appear cut off on smaller screens: The solar system container is fixed at 800px × 800px with overflow: hidden applied to the body. View the page on a desktop screen with a viewport of at least 850px × 850px, or zoom out in your browser (Ctrl + - / Cmd + -) to see Neptune's outer orbit.

Animations or styles not loading: Verify that index.html, styles.css, and script.js are in the exact same directory and have not been renamed.
